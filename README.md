# LiionTR

LiionTR (Lithium-Ion Thermal Runaway) is an open-source research framework
for the multiphysics simulation of lithium-ion battery thermal runaway.

## Current status

Project initialization.

## Planned features

- Global kinetic models
- Heat transfer
- Gas generation
- Pressure evolution
- Vent opening
- Cantera coupling
- ARC/DSC calibration
- Multi-cell propagation
